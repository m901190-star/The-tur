# השקיה — אפליקציה לניהול השקיית העציצים

אפליקציית React Native (Expo) בעברית, שעוקבת אחרי כל עציץ בבית, אומרת כל יום
מה צריך מים, וכותבת תזכורות חוזרות ליומן Google שלך.

## מה האפליקציה עושה

**מסך "היום"** — מה דחוף עכשיו, ממוין מהעציץ שהכי מאחר. מראה גם כמה מים
בסך הכל צריך להיום, כדי שתדע אם לקחת כוס או דלי. כפתור "השקיתי" מאפס את
הטיימר ונרשם בהיסטוריה; "דחה ליום" מזיז את התור קדימה בלי לטעון שהשקית.

**מסך "העציצים"** — כל העציצים, עם חיפוש וסינון לפי חדר.

**מסך העציץ** — כל הנתונים, היסטוריית ההשקיות והדישונים, סנכרון ליומן,
עריכה ומחיקה.

**הגדרות** — בחירת היומן שאליו נכתבות התזכורות, שעת התזכורת, סנכרון מלא
וייצוא קובץ ‎.ics‎.

## מה נשמר לכל עציץ

| שדה | למה הוא שם |
| --- | --- |
| שם | כדי שתזהה אותו ברשימה |
| סוג הצמח | נבחר מתוך 22 סוגים נפוצים בארץ, עם ברירות מחדל וטיפ טיפול |
| מקום בבית | משפיע על צריכת המים, ומאפשר סינון לפי חדר |
| כמות מים | במ״ל, מוצע לפי גודל העציץ |
| תדירות קיץ + תדירות חורף | שתי תדירויות נפרדות — ראה למטה |
| כמות אור | שמש מלאה / חצי צל / צל |
| גודל עציץ | קטן / בינוני / גדול |
| תדירות דישון | אופציונלי, במעקב נפרד מההשקיה |
| תאריך השקיה אחרונה | ממנו מחושב מתי התור הבא |
| תמונה | הכי עוזר לזהות איזה עציץ זה |
| הערות | "רגיש להשקיה יתרה", "העלים מצהיבים" |

## שתי החלטות שכדאי להכיר

**עונתיות.** בחורף הצמחים שותים הרבה פחות. לכן לכל עציץ יש שתי תדירויות,
והאפליקציה בוחרת לבד לפי החודש: אפריל–אוקטובר = קיץ, נובמבר–מרץ = חורף.

**איך התזכורת מגיעה ליומן Google.** האפליקציה לא מתחברת ל-Google ולא מחזיקה
טוקן. היא כותבת אירוע חוזר ליומן של המכשיר, וחשבון Google שמחובר לטלפון
מופיע שם כיומן שאפשר לכתוב אליו — כך האירוע מסתנכרן ליומן Google שלך
כרגיל. בנוסף אפשר לייצא קובץ ‎.ics‎ ולייבא אותו ל-Google Calendar בדפדפן,
או לשלוח אותו למי שמשקה במקומך בזמן חופשה.

כל שאר הנתונים נשמרים במכשיר בלבד (AsyncStorage) ולא נשלחים לשום שרת.

## הרצה

```bash
npm install
npx expo start
```

סרוק את ה-QR עם אפליקציית **Expo Go** בטלפון. התזכורות ביומן והוספת תמונה
דורשות הרשאות שהמכשיר יבקש בפעם הראשונה.

לבנייה לאפליקציה עצמאית (‎.apk‎ / App Store):

```bash
npx eas build --platform android
```

## בדיקות

```bash
npm test        # 52 בדיקות יחידה
npm run typecheck
```

הבדיקות מכסות את לוגיקת החישוב: גבולות העונות, חישוב מועד ההשקיה הבא,
מיון לפי דחיפות, מעבר שעון קיץ/חורף, ובניית קובץ ה-‎.ics‎ (כולל קיפול
שורות לפי RFC 5545 בלי לשבור תווים בעברית).

## הערה על כיוון הטקסט

הממשק כולו עברית, אבל ה-RTL נעשה במפורש בכל סגנון (`row-reverse`,
`textAlign: 'right'`) ולא דרך `I18nManager.forceRTL`. לכן ה-app מכבה את
ה-RTL האוטומטי של מערכת ההפעלה — אחרת שני המנגנונים היו מבטלים זה את זה
והממשק היה מתהפך בחזרה לשמאל-לימין במכשיר שמוגדר לעברית.
