# להתחיל מכאן

## כשאתה מגיע למק

**1. פתח טרמינל והבא את הפרויקט**
```bash
git clone https://github.com/m901190-star/The-tur.git
cd The-tur
git checkout kibbutz-spec
```

**2. התקן את כלי הפיתוח של אפל**
```bash
xcode-select --install
```
בערך 2 ג׳יגה, 10 עד 20 דקות. זה מביא את הקומפיילר ואת ה-SDK של macOS —
כל מה שצריך כדי לבנות מהטרמינל.

**לא** צריך את Xcode המלא (15 ג׳יגה) בשלב הזה. אנחנו בונים דרך CMake ושורת
הפקודה, בלי ממשק גרפי. אם יתברר בהמשך שמשהו דורש אותו — נוריד אותו אז.

**3. פתח Claude Code בתיקייה והגד:**

> קרא את `kibbutz/SPEC.md`. סיימנו את שלב א׳, אנחנו מתחילים שלב ב׳ — השלד.

זהו. כל ההקשר נמצא במסמך; אין צורך לחזור על שום החלטה.

**4. הבא את JUCE** — המסגרת שבה נכתוב את הפלאגין
```bash
git clone --depth 1 https://github.com/juce-framework/JUCE.git ~/JUCE
```

---

## מה קורה בשלב ב׳

פלאגין שנפתח בלוגיק ומראה את המסך — **בלי שום ניתוח אודיו עדיין**.

נשמע מוזר לבנות משהו שלא עושה כלום, וזה בכוונה. המטרה היחידה של השלב הזה
היא לענות על שאלה אחת:

> **האם עברית מתרנדרת נכון בתוך חלון פלאגין בלוגיק?**

זה הסיכון הטכני הגדול בפרויקט. אם יש שם בעיה, עדיף לגלות אותה בשעה הראשונה
ולא אחרי שבועיים של עבודה על עיבוד אודיו.

**מדד הצלחה:** החלון נפתח בלוגיק, כתוב בו "קיבוץ" בעברית, בכיוון הנכון,
והאותיות מחוברות כמו שצריך.
